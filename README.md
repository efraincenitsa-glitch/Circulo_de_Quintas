# Música PRO - Círculo de Quintas

App PWA 100% offline para estudiar teoría musical.

## Funciones
- Círculo de quintas interactivo.
- Escalas mayores, menores naturales y menores armónicas.
- Teclado con notas resaltadas.
- Acordes diatónicos con reproducción de audio.
- Progresiones predefinidas y constructor de progresiones.
- Diapasón para bajo de 4 cuerdas y guitarra.
- Metrónomo.
- Afinador básico usando micrófono.
- Entrenamiento auditivo.
- Buscador básico de acordes.

## Cómo usar en GitHub Pages
1. Sube todos los archivos respetando la estructura.
2. En GitHub abre Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Guarda y abre el enlace publicado.
